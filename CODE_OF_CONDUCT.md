# Code of conduct

Communicate professionally. Critique ideas and behavior using evidence, tradeoffs,
and reproducible facts. Strong technical disagreement is welcome; harassment,
threats, discriminatory abuse, doxxing, and disclosure of confidential data are not.

The maintainer may moderate or restrict participation based on severity and
repetition. A confidential conduct-reporting channel must be confirmed before
public community participation. During local foundation work, concerns can be
raised directly in the existing private project conversation. Reports involving
a maintainer should be reviewed by an uninvolved person where possible.
