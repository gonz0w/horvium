# Inactive original dashboard witness fixture

Date: 2026-10-13. Status: implementation candidate; native execution pending.
Owner: [issue 382](https://github.com/gonz0w/horvium/issues/382).
Authority: [ADR 0011](../../adr/0011-native-dashboard-witnesses.md),
[EDD](../../design/dashboards/native-witness-binding-EDD.md) and
[Test Design](../../design/dashboards/native-witness-binding-TDD.md), adopted in
[PR 387](https://github.com/gonz0w/horvium/pull/387).

Test-only Go helpers independently decode original version-1 frames, retain exact
integers, reject ambiguity/order/bounds/identity errors, seal exclusive raw objects
and forward original bytes. Source completeness, delivery and publication are
separate facts. The controller confirms only existing Overview metadata; it never
uses management numeric values as expectations. Missing/expired lineage denies,
failed confirmation is permanent, and concurrent lookups share one metadata call.

The disposable FreeBSD observer reexecutes the original fixture artifact. An owned
connector starts with the configured unprivileged credentials before connecting,
passes one established descriptor, receives acknowledgment and exits. Actual guest
base headers supply credential/process layouts through an archived development C
probe. UID/PID, process start, executable bytes and original socket objects bind
actors. The helper/management binaries and public wire/config/API remain unchanged.
The temporary originals use root-only bounded tmpfs; all process/socket/mount and
original artifact cleanup must be independently observed.

`TestNativeDashboardWitnessShort` is a reduced test of native and 10,000-dataset
projection pairs, exact original HTML and deliberate mutations, unrelated same-UID
denial, real helper command/guard death, stale original retention and helper epoch
recovery. It requires the existing explicitly disposable performance guest flags,
original candidate build/guest preflight and signed local review. Its private raw
originals, probe and transcripts are evidence, never public inventory fixtures.

The resource runner remains on its existing frozen oracle. The full adopted native
short fault/custody/calibration controls, instrumentation-inclusive budgets,
supplemental independently reopened coverage and complete both-release resource
procedure remain gates; the reduced test cannot activate or accept them. Historical
failures and skipped releases retain their original scope. Runtime writes stay
disabled; broader dashboard, browser, native safety, hardware and release gates stay
open. This fixture adds no installed service, tracking automation or runtime C
dependency.
