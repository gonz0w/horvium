# Actual controller interruption with a surviving owner

Status: inactive test-only fixture; broader native/resource gates remain open.
Owner: [issue 382](https://github.com/gonz0w/horvium/issues/382).
Authority: [ADR 0011](../../adr/0011-native-dashboard-witnesses.md),
[EDD](../../design/dashboards/native-witness-binding-EDD.md),
[Test Design](../../design/dashboards/native-witness-binding-TDD.md),
DASH-WIT-003 / DASH-WIT-006 / DASH-WIT-NATIVE-005.

Earlier observer/connector signals and controller-channel EOF are not death of
the actual controller. This fixture introduces a separately surviving original
FreeBSD owner for that process-lifetime boundary, using the existing kernel
reaper, original artifacts, socketpairs and disposable storage owner. It changes
no product executable, public wire/API/configuration, installed service or runtime
dependency. Runtime writes and the canonical resource runner stay inactive.

## Ownership and observable cases

The surviving owner retains the real product helper/manager, both configurations,
token digest, tmpfs/underlying directory identities and original ZFS/md fixture.
It launches one byte-verified controller reexecution. That controller creates the
observer's control/fault socketpairs and launches the actual observer; it is the
sole owner of their parent ends. The survivor's separate inherited channels only
relay explicit controls and original boundary events. They never hold an observer
parent-end duplicate. Normal/timed paths retain their existing direct owner.

Verify original UID/PID/start-time/artifact roles and kernel parent relationships:
owner -> controller -> observer. Kill only the still-original controller handle,
using SIGTERM or SIGKILL at each actual capture, sealed, forward and metadata
boundary. Those eight cases retain the original fault gates and normal deadlines.
The normal control confirms a complete, delivered, actually published producer
original through the controller, then stops both controller and observer cleanly.
It is not a signal-death control.

After controller death, original channel closure must cancel the observer's work
and stop admission. The observer writes an exclusive root-only sealed terminal
receipt before trying to report to its now-dead controller. This persistence is
restricted to the eight exact private controller labels; it does not grant a
reader access or turn failure into success. The survivor reaps the adopted
observer with PID-specific Wait4, preserving the actual controller signal wait,
observer exit status and both wait-usage records. Never signal saved foreign PIDs
or count a vanished PID as proof of reaping. Unknown lineage/wait/cleanup fails
and requires discarding the disposable guest.

Require failed terminal evidence, absent original front socket, no active call or
connector, all-started connector reaping and refusal of control/original lookup.
Join the original pending metadata lookup and require failure before closing the
survivor's root, so a closed-directory error cannot manufacture witness denial.
The actual helper/socket and both configurations/token must remain unchanged.
The surviving owner then stops its product processes and verifies its original
storage teardown; controller death is not helper death or host shutdown.

## Original custody and evidence

Preserve every actual producer original or interrupted prefix, including unindexed
files and their original 0400/0600 modes. Record original file object/UID/link/size,
complete bytes and SHA-256 with before/after checks. Copy to exclusive sealed
private exports before exact tmpfs unmount and underlying-directory removal.
Complete/delivered producer facts remain separate from a failed candidate's
eligibility. Metadata interruption can retain a complete delivered original;
capture/forward uncertainty must never acquire that claim from byte agreement.

Run one signed clean reviewed source on both pinned disposable FreeBSD/amd64
releases, sequentially. Independently reopen case/terminal receipts, actual wire
frames or partial prefixes, source/artifact/actor/ABI bindings, original preflight
and guest/host teardown. Preserve all failed, skipped and historical limitations.
The bounded outer diagnostic allowance covers the larger lifecycle matrix; no
product, bootstrap, normal collection, archive, frame or attempt limit is raised.
No operator disks, datasets, snapshots or backup history are fixtures.

## Remaining acceptance

This matrix covers the explicitly owned controller and inherited channels, not
loss of the independent surviving owner or host power loss. Remaining full
broker/caller capacity and cancellation/recovery, historical 14.5 sampling gaps,
cadence/overhead/augmented budgets, 300-second idle, original latency/full resources,
browser/manual accessibility, hardware and release acceptance remain open. A
merged component never closes full native 005 or resource acceptance by itself.
Run required check/lint/test/secrets, affected-package review and lab-stop/status.
No new Actions, paid automation or tracking service is added.

## Retained failed first candidate

Source `f9496760308232877e9c48dd069d13338938c0c3` failed its 15.1 matrix
after 568.98 seconds; all nine cases failed. Normal export rejected an existing
`.wire.json` index sidecar. Signal cases passed a raw WaitStatus exit code to a
connector predicate that expects normalized signal-death codes, then attempted
graceful cleanup through an already-dead controller proxy. Guest cleanup was
unverified. The host discarded its disposable VM and verified complete host
process/listener/key/image/variables teardown. This source has no 14.5 execution.

Its archive retains the actual failed transcript, eight failed terminal receipts
and one normal original export. It lacks completed per-case wait/usage receipts
and adverse producer-byte exports. Terminal original references are not reopened
producer bytes; they cannot acquire that claim later. Guest cleanup remains failed
and the candidate remains unqualified. Historical manifests are not changed.

A portable behavioral regression reproduces rejection of the raw signal result:
`exited=false, code=-1, signal=15`. A dedicated raw-controller predicate now checks
that representation without changing the connector's normalized contract. Export
validates existing sidecars against the original final sealed records and preserves
their actual bytes/object/hash separately. Failure cleanup never sends graceful
stop to a dead proxy: the surviving owner closes it, reaps its known observer and
retains an available final index for fallback export before ordinary pair cleanup.
